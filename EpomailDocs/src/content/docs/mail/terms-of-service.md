## 3. 账号与安全

1. **注册信息真实**：注册仅需一个有效的收件邮箱地址与密码。请勿冒用他人名义或使用您无权使用的域名。
2. **凭证保管**：您对账号密码、两步验证凭据与 API 令牌的保管负责。经由您的凭证发生的操作视为您本人的操作。
3. **两步验证**：强烈建议启用 TOTP 或通行密钥。在「加密邮件模式」的实例上，运营者可能依据安全策略强制要求开启两步验证。
4. **登录保护**：连续 5 次密码错误将锁定登录 12 小时；同账号最多同时保持 10 个活跃会话，您可随时在设备上退出登录以吊销令牌。
5. **保留字**：`admin` 等管理员标识为系统保留，无法用于普通注册。
6. **注册密钥**：运营者可将实例配置为「凭注册密钥注册」或「关闭注册」，这是实例的自主管理权。

- 将本服务用作匿名转发跳板、短期一次性滥发池，或以规避封禁为目的反复注册。

- 侵犯他人知识产权、隐私权或肖像权；伪造发件人身份（spoofing）冒充他人或机构发送邮件；

运营者可依据违规的性质与严重程度，采取：警告 → 功能限流 → 垃圾邮件隔离 → 暂停账号 → 物理删除账号及全部数据。涉及违法行为的，运营者可依法保存必要证据并配合有权机关。若您的行为导致运营者被 Cloudflare 或上游服务商处罚，运营者保留向您追偿的权利（见第 12 节）。
